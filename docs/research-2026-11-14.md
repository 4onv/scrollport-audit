| Inspect the ancestor taking over CSS scrolling | Modern Web Guidance #3603 at 12:40:01 UTC reported sticky and view timelines attached to an overflow wrapper without a useful scroll range. [Issue](https://github.com/GoogleChrome/modern-web-guidance-src/issues/3603) | Chrome has scroll badges and Bramus's DevTools extension visualizes animation ranges. A small standalone inspector can expose the entire computed chain, including zero-range ancestors, cross-axis values, and body-to-viewport propagation. [Chrome DevTools](https://developer.chrome.com/docs/devtools/elements/badges/) · [Scroll-driven Animations Debugger](https://github.com/bramus/scroll-driven-animations-debugger-extension) | Download one HTML file to reproduce the failure, then use one snippet on a selected element. | Preview composed code review rules per path | Open Code Review #1934 at 13:54:41 UTC asked for reusable rule fragments to avoid drift across language-specific files.
